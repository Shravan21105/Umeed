# Umeed

Welcome to the **Umeed** frontend repository! This is a modern, responsive React application built to support and showcase the initiatives of Umeed. As a purely frontend project, it handles all routing, UI, and interactions on the client side. 

🚀 **Live Demo:** Don't want to clone the repo locally? You can view and interact with the live project here: [https://umeed-gamma.vercel.app/](https://umeed-gamma.vercel.app/)

## Our Mission & Vision

**Empowering Specially-Abled Children & Families**

At Umeed Project, our mission is to bring quality education and equal opportunities to specially-abled children, particularly in the Vidarbha region of Maharashtra. We work closely with educators, caregivers, and communities to create a nurturing environment where every child can learn and grow with dignity and respect. 

In the next 5 years, Umeed Project envisions transforming Vidarbha into a model region for inclusive education & empowerment by expanding inclusive schools, spreading awareness, introducing assistive technology, and driving public-private collaborations.

## What We Provide

- **Inclusive Learning & Special Education**: Customized learning techniques and education plans for children with diverse needs.
- **Psychological Support**: 24/7 emotional guidance and counseling for children and parents.
- **Vocational Training**: Practical skills to help children become independent.
- **Schools Directory**: A curated list of schools in the Vidarbha Region that offer supportive education for specially-abled children.
- **Resources Hub**: A vast collection of learning materials, including educational videos, mobile apps (like Be My Eyes, ISL Journey), reading material, and links to government schemes and scholarships.
- **Events & Community**: A platform to discover and add events to foster community involvement and awareness.

## Project Features & Accessibility

Umeed is built with accessibility and ease of use in mind:
- **Voice Commands**: Navigate the site completely hands-free by saying commands like "OPEN: Home" or "SCROLL: Down".
- **Speech-to-Text & Text-to-Speech**: Built-in tools for seamless communication and content consumption.
- **Responsive Design**: Fully functional on desktop, tablet, and mobile devices.
- **Dark Mode**: Built-in support for theme switching (Light/Dark mode) for better visual comfort.
- **Donation Integration**: Integrated securely with Stripe to support our cause.
- **Form Handling**: Contact and contribution forms powered by EmailJS.

## UI & Design Highlights

- **Welcoming Visuals**: A calming, vibrant color palette (featuring soft purples, yellows, and whites) paired with modern glass-morphism effects.
- **Inclusive Illustrations**: Beautiful, custom 3D illustrations featuring specially-abled children (e.g., in wheelchairs or using walking canes) to create a warm and representative environment.
- **Clean Layouts**: Carefully organized tabular data (like the Schools Directory with embedded map thumbnails) and neatly structured grid layouts (like the Resources Hub with video and app cards) for optimal readability.

## Tech Stack

- **Framework:** React 19 + Vite
- **Styling:** Tailwind CSS + PostCSS
- **Routing:** React Router v7
- **Animations:** Framer Motion
- **Payments:** Stripe (`@stripe/react-stripe-js`, `@stripe/stripe-js`)
- **Accessibility:** ResponsiveVoice (Text-to-Speech / Voice Commands)
- **Icons:** Heroicons & Lucide React
- **Email:** EmailJS

## Getting Started

Follow these instructions to set up the frontend project locally.

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. Clone the repository:
   ```bash
   git clone <your-repo-url>
   cd Umeed
   ```

2. Install the dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to `http://localhost:5173`.

## Scripts

- `npm run dev`: Starts the local Vite development server.
- `npm run build`: Builds the application for production.
- `npm run lint`: Runs ESLint to check for code quality issues.
- `npm run preview`: Locally preview the production build.
